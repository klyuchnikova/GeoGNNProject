# Results protocol

Do not place manually copied scores here. The authoritative files are generated by the run:

```text
artifacts/results/<run>_metrics.json
artifacts/results/<run>_history.csv
artifacts/results/metrics_comparison.csv
```

Recommended final reporting:

| Model | Acc@1 | Acc@5 | Acc@10 | MAP@5 | MAP@10 | MRR |
|---|---:|---:|---:|---:|---:|---:|
| Global popularity | generated | generated | generated | generated | generated | generated |
| Personal popularity | generated | generated | generated | generated | generated | generated |
| Full Graph-Flashback | generated | generated | generated | generated | generated | generated |

Run at least three seeds for the chosen configuration and report mean ± standard deviation. City selection and hyperparameters must be fixed before reading final test metrics.
