# Источники данных

## Gowalla

- SNAP check-ins: `https://snap.stanford.edu/data/loc-gowalla_totalCheckins.txt.gz`
- SNAP friendship graph: `https://snap.stanford.edu/data/loc-gowalla_edges.txt.gz`
- SNAP description: `https://snap.stanford.edu/data/loc-gowalla.html`
- Figshare article used to locate spot metadata: `https://figshare.com/articles/dataset/gowalla_data/22126586`

The downloader queries the Figshare API and selects `gowalla_spots_subset1.csv` by filename rather than hard-coding an expiring file URL.

## Foursquare

- TSMC2014 NYC/Tokyo Kaggle mirror: `chetanism/foursquare-nyc-and-tokyo-checkin-dataset`
- Original public dataset page: `https://sites.google.com/site/yangdingqi/home/foursquare-dataset`

Downloaded datasets are not included in this repository or ZIP.
